Migrated from Wix and now ranks top for political consulting searches.

**Tech:** React, TypeScript, Tailwind CSS, Framer Motion, react-helmet-async, Vite

Implemented REST API connections and comprehensive testing for robust system integration.

**Tech:** C#/.NET, FlowFactory, Azure AI, Jira API, REST APIs
